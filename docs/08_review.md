## Review 检查清单

每次审查必须逐项确认：

- [ ] 代码符合架构设计（模块划分、依赖关系）
- [ ] 代码符合编码规范（命名、注释、文件组织）
- [ ] 无安全漏洞（注入、XSS、权限漏洞）
- [ ] 无性能隐患（N+1 查询、内存泄漏、阻塞调用）
- [ ] 错误处理完整（无空 catch、边界条件覆盖）
- [ ] 测试覆盖充分（公共函数有测试、AAA 模式）
- [ ] 无调试代码残留（console.log、print 等）
